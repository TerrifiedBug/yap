Measured on an M4, p50, and roughly twice as quick as Handy on the same model. Don’t take our word for it: yap bench --audio FILE times it on your own machine, and the tables come with the commands that made them.

Two lines, then it’s yours.

brew install --cask terrifiedbug/tap/yap

yap setup asks for the permissions and pulls the model down. That is 220 MB, once, and then you are offline forever.

Builds are signed with a Developer ID certificate and notarized by Apple, so there is no Gatekeeper prompt. The network gets used exactly once, to fetch the model.

The entire manual.

Hold

Press and keep fn down. A small pill shows the mic is live. Some other key, if you’d rather; that is one line in the config.

Speak

Say the thing. Nothing is streaming anywhere; the audio never leaves the machine.

Let go

About 60 ms later the words are at your cursor, in whatever app you were already in.

Meetings, both sides of them.

The recorder takes your mic and the system audio as two separate tracks and gives you one transcript, with timings and speaker labels. It shares one process and one loaded model with dictation, so nothing extra is resident.

Turn on meeting_detection and yap offers to record when something else grabs the mic. Off by default, and nothing is watching until you turn it on. The only thing it ever does on its own is one device read a second.

# transcript.md (invented; the real ones stay on your disk)
engine: parakeet (parakeet-tdt-ctc-110m)

[0:04] them: Can everyone see the dashboard?
[0:07] me: Yep, sharing works.
[0:12] them: Deploy went out at nine. Zero regressions so far.
[0:19] me: Latency graph stayed flat all morning.
[0:26] them: Good. Ship the changelog and we are done.

# made with: yap record, ^C to stop

One config file. Flip it live.

{
  "recordings_dir": "~/Recordings",
  "meeting_detection": false,
  "mic_voice_processing": true,
  "transcription": { "enabled": true },
  "dictation": {
    "model": "parakeet-tdt-ctc-110m",
    "hotkey": "fn",
    "overlay": true,
    "newline_after_release": false,
    "mute_output": false
  }
}

Save the file and yap picks it up; these four change on the spot, no restart. ~/.config/yap/config.json, every key optional.

They live in the shared FluidAudio cache, so anything else built on it reads the same files; the download happens once per machine, not once per app. Set model in the config to swap.
